# 秋夕-PDF阅读器 · 插件市场（Plugin Store）

> **状态（2026-10-28，对应客户端 2.0.0.0）**
>
> 2.0.0.0 实现的是**安装包式**市场：清单条目带 `download` / `sha256` / `size`，阅读器下载包体、
> 校验摘要后再安装。主题包写进「设置 → 外观」，功能插件进右栏「插件商店」。
>
> 1.9.0.0 及更早的「配色值式」清单（条目直接带七个颜色、不下载包体）已不再被支持，
> 给 2.0.0.0 喂那种清单会得到一行「清单格式不支持」。迁移方法见 `docs/PUBLISHING.md`。

本仓库只放**清单与规则**，不放可执行代码。阅读器通过 HTTPS 拉取 `index.json`，
按条目下载主题包 / 插件包（zip），校验 SHA-256 后再安装。

## 目录

```
index.json                 # 唯一清单入口（阅读器默认拉这个）
schema/plugin.schema.json  # 条目结构（JSON Schema 2020-12）
docs/API.md                # 接口与字段约定
docs/PUBLISHING.md         # 上架流程
packages/<id>/<version>/   # 可选：由维护者托管的包体（也可用 Release 附件直链）
```

## 这是什么

- **主题包**（`kind: "theme"`）：一套 `theme` / `themeLayout` / 调色凭据 + 可选背景图，安装后出现在「设置 → 外观 → 主题商店」。
- **功能插件**（`kind: "plugin"`）：`.qxplugin` 包（zip + `manifest.json`），装完在功能区「开始 → 插件」出现命令。

### 插件怎么执行

插件是**用户自己安装的第三方包**，来源可以是清单里的一键安装，也可以是本地文件；安装动作由用户在客户端里确认。

- 清单里必须声明权限：**读取文档内容 / 保存文件 / 联网 / 弹出提示框 / 修改设置**。客户端运行期逐项校验，没声明就调用会被直接拦住并记录日志。
- 插件跑在主进程的**隔离上下文**里，拿不到 Node 的 `require`，只能通过宿主给的受限接口做事。
- 插件崩溃时客户端会弹框让用户选「禁用这个插件」还是「重试一次」，不会静默失败。
- 插件的文件、启用状态与卸载都在用户本机，服务器不保存任何用户数据。

## 安全与隐私

- 清单与包体都走**普通 HTTPS 静态文件**，不带任何凭据（内置凭据通道只用于官方部署发行版，不在本仓库）。
- 阅读器只信任 `index.json` 里显式的 `https://` 直链，拒绝 `file:`、`javascript:`、本地地址。
- 每个包必须给 `sha256` 与 `size`，校验不过直接丢弃并提示。
- 不收集任何用户信息；不做统计上报。

## 责任边界

本仓库与镜像站只做两件事：**托管 `index.json` 清单**、**托管 `.qxplugin` / 主题包文件**。

- 不执行任何插件代码，也不对插件的行为负责；插件的执行只发生在用户机器的阅读器里。
- 不对任何第三方包做安全审计或背书；清单里的条目只保证格式合法、`sha256` 与 `size` 与被托管的文件一致。
- 用户发现可疑插件时，应停止使用并在客户端里卸载，同时通过 Issues 告知维护者以便从清单移除。
